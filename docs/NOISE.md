# Noise Robustness Scorecard

本番経路 (LID→ルーティング→デコード→ja句読点) を、クリーン音声と white/pink/babble ノイズ (SNR 20/10/5/0dB) を重ねた音声の両方で評価。metricは en=WER, 他=CER（yueはt2s正規化）。

## ノイズ生成条件

- SNRは対象音声のRMSパワー基準: `10*log10(P_speech/P_noise) == SNR_dB`
- noise種別: white（ホワイトノイズ）, pink（1/fピンクノイズ）, babble（同一プールの別言語クリップを2〜3本ランダムに重ねた話し声ノイズ、対象と同言語は使用しない）
- SNRレベル: 20, 10, 5, 0 dB
- 乱数seed: 42（固定・再現可能、`scripts/make_noisyset.py` 参照）
- クリッピング防止: 混合波形のピークが1.0を超える場合は全体をスケールダウン
- 生成スクリプト: `scripts/make_noisyset.py` / 評価スクリプト: `scripts/eval_noise.py`
